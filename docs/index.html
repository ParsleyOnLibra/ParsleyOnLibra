01 / ABOUT

어떤 문제를 풀어왔는가

현장에서 찾은 문제를 재현 가능한 정보로 바꾸고, 다음 검증을 더 쉽게 만드는 데 관심이 있습니다.

로보티즈에서 액추에이터 조립·품질 검사와 성능 테스트를, 유진로봇에서 AMR의 도킹·맵 작성·속도 제어·장애물 회피 등을 검증했습니다.

장애가 발생하면 로그와 재현 조건, 발생 빈도, 영상을 모아 이슈를 정리했습니다. 반복 테스트는 Python과 Selenium으로 자동화해 관찰할 기회를 늘렸습니다.

최근에는 공개 수면 데이터를 분석하며 정확도뿐 아니라 신호 품질과 놓친 사례도 함께 확인하고 있습니다.

HOW I WORK

“숫자가 좋아 보여도, 실제로 놓친 장면은 없는가?”

테스트 환경을 정리하고, 반복을 자동화하고, 결과를 원본 데이터와 대조합니다. 협업하는 사람이 바로 다음 행동을 할 수 있도록 기록합니다.
