SCOPE & LIMITS

확인하지 않은 범위

UTM VM의 SLAM 지도 작성·목표 주행, Windows PC VM의 Ubuntu·ROS 2·RViz 실행, 실제 배터리 센서, 무선 통신, 장애물 회피·도킹, 실물 로봇은 검증하지 않았습니다. 기존 Docker 지도의 범위는 부분 지도이며 동일한 PGM 파일만으로 탐색 범위가 늘었다고 주장하지 않습니다. 사용자의 별도 직접 실행·이해도 답변은 아직 기록되지 않았습니다.
